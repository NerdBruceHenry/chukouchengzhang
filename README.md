# 🖌️ 出口成章 — 陪孩子从小学到大学的中文表达成长工具

帮助孩子提升**遣词造句、阅读理解、写作、口才与沟通**能力，目标是让孩子的中文输出——不管是写作还是口语——都能达到**出口成章**的水平。

和《Spoken Like a King》《思维超能力》是同一个系列：纯网页应用（PWA），手机、平板、电脑打开就能用，可以"添加到主屏幕"，可以离线，没有广告，所有数据只存在本机浏览器里。

吉祥物是一支会说话的小毛笔 **墨墨**。

---

## 设计思路：出口成章 = 输入 → 内化 → 输出

| 原则 | 在工具里怎么体现 |
| --- | --- |
| **先有积累才有输出** | 词语、成语、好句、诗句都能一键收藏进「我的素材本」；写作时素材本里的词会出现在编辑器上方，点一下就能用 |
| **学会 ≠ 会用（迁移）** | 素材本里的词要在自己的作文、口头表达、造句里**用出来两次**才算"掌握"，工具会自动统计 |
| **写和说是同一种能力** | 同一套结构（总分总、起承转合、观点-理由-例子-重申）既用于写作也用于演讲；写作可以口述，口语会转成文字分析 |
| **遣词造句靠对比练出来** | 平淡句 vs 生动句、"高兴"有多少种说法、近义词辨析、病句医院、句子升级 |
| **口才要量化才看得见进步** | 每次说话统计字数、语速（字/分钟）、口头禅（嗯/然后/那个……）、用词丰富度、用到的成语，录音保存，画出进步曲线 |
| **沟通是可以练的技能** | 20 个真实情境（道歉、拒绝、说服、安慰、批评与反馈、面试、主持冷场、辩论），选出最得体的回应再亲口说一遍；附"观察-感受-需要-请求"等 6 个沟通方法 |
| **阅读要有策略** | 每道阅读题都标注用到的策略：细节、词句、推理、概括、结构、感悟 |
| **不会忘** | 学过的成语和诗词按 1→2→4→7→15→30→60 天自动安排复习 |
| **有趣才能坚持** | 每日任务（约 15 分钟）+ 宝箱、经验称号（小书童 → 文曲星）、连续打卡、16 枚徽章、飞花令、成语补全 |
| **随孩子一起长大** | 6 个阶段：🌱萌芽（一二年级）→ 🌿抽枝（三四年级）→ 🌳成林（五六年级）→ 🚀启航（初中）→ 🔭远望（高中）→ 🌌星辰（大学及以后） |

## 功能一览

**积累**
- 📚 **词语工坊**：约 200 个分级成语（意思、例句、成语故事、用它造句）、看意思猜成语、成语补全、近义词辨析、词语搭配、"换个好词"60 秒挑战、16 组分类好词
- 🏮 **诗词经典**：107 首分级古诗词，每日一诗、朗读节奏线、逐字朗读反馈、背诵挑战、接下句、**飞花令**
- 📒 **我的素材本**：收藏的好词好句，自动统计"用出来"的次数
- 🔁 **复习**：记忆曲线

**组织**
- ✏️ **造句擂台**：句子升级、扩句、连词成句、修辞侦探、句式变换、关联词、病句医院
- 🔍 **阅读侦探**：28 篇分级短文（原创现代文 + 经典文言文），读前预测、听全文、朗读一段、策略答题、摘抄好句、读后复述

**输出**
- 📝 **写作工坊**：8 种结构模板（附范文）、开头结尾各 8–9 种、8 个写作技法对比、20 个分级练笔题、8 个仿写练习、作品集；写完立刻给出**表达力分析**（修辞、五感、好词、句子节奏、关联词、"然后"太多等）
- 🎤 **口才训练营**：即兴说、一分钟演讲（框架 + 开场白示范 + 提纲）、复述故事（关键信息覆盖率）、看图说话、普通话绕口令、停顿与重音
- 🤝 **沟通情境**：20 个情境 + 沟通工具箱
- 🤖 **AI 小老师（可选）**：作文批改（2 个亮点 + 1 处修改 + 好词推荐 + 启发提问，不代写）、口头表达点评、辩论陪练（AI 站在对立面，并给出"教练提示"）

**成长**
- 📈 **成长档案**：七项能力雷达图、口头表达字数和口头禅曲线、12 周打卡热力图、徽章墙
- 👨‍👩‍👧 **家长中心**（乘法题验证）：学习概况、阶段/目标/语速设置、孩子录音回放、AI 设置、数据备份导入、家长建议

## 怎么用

### GitHub Pages（推荐）
1. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。
2. 推送到 `main` 后 Actions 会自动测试并部署，地址：`https://<用户名>.github.io/chukouchengzhang/`。
3. 用 iPad / 手机打开，浏览器菜单选"添加到主屏幕"。

> 语音识别和录音要求 **HTTPS**（GitHub Pages 自带）或 `localhost`。

### 本地运行
```bash
python3 -m http.server 8000
```
然后打开 http://localhost:8000

## 浏览器建议

| 设备 | 推荐 | 说明 |
| --- | --- | --- |
| iPad / iPhone | Safari | 支持中文语音识别，效果好 |
| 安卓 | Chrome | 语音识别需要能访问 Google 服务，国内网络下可能不可用 |
| 电脑 | Edge / Chrome | Edge 自带很自然的中文 "Natural" 声音 |

不支持语音识别的浏览器会自动改用"录音 + 和示范对比 + 自评"。

## AI 小老师（可选）

家长在"家长中心 → AI 小老师"填入自己的 Anthropic API Key（默认模型 Claude Opus 5.5，也可选 Claude Sonnet 5.5）。Key 只保存在本机浏览器，只发送给 `api.anthropic.com`。AI 的原则是**先肯定、只提最重要的一两条、绝不代写**。

## 技术说明

- 纯 HTML/CSS/原生 JavaScript（ES Modules），**无需构建**，无第三方依赖（AI 小老师使用时才从 CDN 加载 Anthropic 官方 JS SDK）。
- 朗读：优先播放 `audio/` 下预先生成的自然普通话音频（开源模型 Kokoro-82M-v1.1-zh，Apache-2.0）；没有预生成音频的内容使用浏览器自带的中文语音。
- 识别：Web Speech API（`zh-CN`），逐字对齐（最长公共子序列）给出朗读反馈。
- 进度：localStorage；录音：IndexedDB（最多 40 条）；可导出/导入 JSON 备份。

```
js/app.js            路由、首页、计时、首次引导
js/state.js          进度、素材本、作品集、间隔重复
js/speech.js         朗读、识别、录音
js/score.js          朗读比对、流利度、写作表达力分析（有单元测试）
js/components.js     朗读卡、选择题、计时说话等通用组件
js/views/*.js        各模块页面
js/data/*.js         课程内容（成语、诗词、造句、阅读、写作、口才、沟通、徽章）
tools/               离线缓存列表生成、语音生成脚本
tests/               node --test 单元测试 + 内容格式检查
```

运行测试：`npm test`　　修改文件后更新离线缓存：`npm run build:sw`

### 扩充内容

所有内容都在 `js/data/` 下，是普通的 JS 数组，照着现有格式添加即可；`npm test` 会检查答案下标、重复、关键词等格式问题。
